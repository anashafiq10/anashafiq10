I like digging into data to find out what's actually going on, and building things other people can use. Most of my work so far is analytics and machine learning in Python and R.

## What I've worked on

- **Analytics at Tenaga Nasional Berhad (TNB)**: explored 2M+ outage records in Python and built 15+ visualizations that fed a multi-phase infrastructure investigation; reviewed electricity-theft detection models; automated ETL pipelines in R.
- **NLP**: a multilingual BERT sentiment pipeline (98.7% accuracy) with a Streamlit app for non-technical users.
- **Machine learning at scale**: PCA and k-Means on datasets larger than local memory, run on a remote Linux cluster.
- **Computer vision**: multi-view 3D reconstruction and epipolar geometry, built from scratch in MATLAB.
